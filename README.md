# Vigilo Orders

Ce dépôt contient les versions Windows de l’application Vigilo Orders.

## Téléchargement

Téléchargez la dernière version depuis la page
[Releases](https://github.com/Axonovia/vigilo-orders-releases/releases/latest).

Pour une installation normale, choisissez le fichier dont le nom se termine par
`setup.exe`. La version portable est réservée aux besoins ponctuels ou à
l’assistance.

## Mise à jour

La version installée vérifie automatiquement si une mise à jour est disponible.
Elle vous demande toujours confirmation avant de l’installer et de redémarrer
l’application.

## Guide d’installation

Le guide vidéo est disponible sur la
[page de téléchargement Vigilo](https://download-vigilo.axonovia.com/installation).

En cas de difficulté, contactez Axonovia avant de modifier les fichiers de
l’application.
